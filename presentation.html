🐞 Defect Tracking & Resolution Log

DEF-01: Browser WebM Audio Decoding [High]
Defect: Browser MediaRecorder WebM blobs caused format decode errors in standard WAV pipelines.
Resolution: Integrated Web Audio API AudioContext.decodeAudioData with PCM float conversion.
DEF-02: Low-Frequency Microphone Rumble [Medium]
Defect: Sub-80Hz ambient room rumble distorted fundamental Sa histogram peak detection.
Resolution: Applied 2nd-order Butterworth 80 Hz High-Pass Filter in scipy.signal before pYIN.
DEF-03: LLM Latency & Offline Fallback [Medium]
Defect: External LLM latency or network timeouts risked pedagogical chat failure.
Resolution: Built resilient Offline Classical Pedagogical Guru fallback in providers.py.
DEF-04: Cross-Origin Resource Sharing [Low]
Defect: Strict CORS policy blocked local Next.js port 3000 requests to port 8000.
Resolution: Configured regex origin allowlist https?://(localhost|127\.0\.0\.1)(:[0-9]+)?.
